# RouteAI

AI-powered route planning prototype.

## Current prototype
- Natural-language route request
- Voice input where supported
- Smart destination detection for common examples
- Optional food/coffee stop concept
- Opens the route in Google Maps
- Responsive mobile-first design

## Next production integrations
- Real AI intent extraction
- Google Maps / Apple Maps routing
- Live traffic
- Places search and recommendations
- Multi-stop optimization
- User location and ETA
- Authentication and saved trips
